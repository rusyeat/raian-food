# Raian Food

Қазақша және орысша мәзір, себет және WhatsApp арқылы тапсырыс беру. HTML, CSS, JavaScript; сыртқы framework және ақылы сервис қажет емес.

## Іске қосу

Node.js 20 немесе жаңарақ:

```sh
npm start
```

Сайт: http://127.0.0.1:4173. Тексеру: `npm test`.

GitHub Pages жариялауға дайын файлдар `dist/` ішінде. Барлық сілтеме салыстырмалы, сондықтан GitHub жобасының ішкі жолында жұмыс істейді.

## Тапсырыс жолы

1. Тағам, нұсқа және санын таңдау.
2. Жеткізу (500 ₸), алып кету немесе залды таңдау.
3. Аты-жөні, телефон, қажет болса жеткізу мекенжайы немесе үстел/күн/уақыт енгізу.
4. Төлем нұсқаулығы және тапсырысты алдын ала қарау.
5. WhatsApp-та дайын мәтінді ашу; клиент «Жіберу» батырмасын өзі басады.
6. Қызметкер қолжетімділікті, жеткізу аймағын немесе үстелді және төлем реквизитін растайды.
7. Клиент төлеп, чекті сол WhatsApp чатына тіркейді. Төлемді қызметкер тексереді.

Kaspi QR берілмеген, сондықтан QR уақытша қолжетімсіз деп анық көрсетіледі. Жалған QR, автоматты төлем растауы немесе автоматты бронь жоқ.

## Үстелдер

Иесі растаған 6 үстел, әрқайсысы 4 орын. Экрандағы нөмірлер — таңдау үшін берілген шартты сызба. Нақты бос орындар онлайн синхрондалмайды. Таңдау — қызметкер растауы қажет өтінім. Нақты уақытта ортақ бронь базасы үшін сервер мен қызметкер интерфейсі керек.

## Өзгерту

- `dist/domain.js`: мәзір, бағалар, нөмір, жеткізу құны, үстел саны.
- `dist/i18n.js`: екі тілдегі мәтіндер және FAQ.
- `dist/style.css`: дизайн және мобильдік нұсқа.
- `dist/assets/`: SVG логотип және жергілікті WebP суреттер.

Себет, тіл және тапсырыс түрі браузердің localStorage жадында сақталады. Аты-жөні, телефон және мекенжай тек ашық бет жадында болады; localStorage-қа жазылмайды. Сайтта аналитика, логин, төлем деректерін жинау және серверге форма жіберу жоқ. Карта провайдері iframe ашылғанда техникалық сұрауды алады. WhatsApp тапсырыс сілтемесінде клиент өзі жіберетін мәліметтер болады.

## Қайта жариялау

Негізгі код `main` тармағында, дайын сайт `gh-pages` тармағында:

```sh
npm test
git add .
git commit -m "Update Raian Food"
git push origin main
git subtree push --prefix dist origin gh-pages
```

Төлемге арналған QR мен нақты тағам фотоларын кейін осы файлдарды өзгерту арқылы қосуға болады. GitHub Pages мекенжайы — тегін хостинг адресі; жеке сатып алынған домен емес.
